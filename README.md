# Elite Personal Portfolio - Ronak Kumar

A premium, interactive, and highly optimized personal portfolio for **Ronak Kumar** (B.Tech Civil Engineering, IIT Roorkee). This portfolio is designed to showcase expertise in Software Engineering, Competitive Programming, Machine Learning, and Quantitative Finance.

🌍 **Live Website:** [https://ronak-portfolio-gamma.vercel.app](https://ronak-portfolio-gamma.vercel.app)

## 🚀 Tech Stack

Built with cutting-edge technologies to ensure a dynamic and lightning-fast user experience:

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS & Glassmorphism
- **Animations:** Framer Motion
- **3D Graphics:** Three.js, React Three Fiber, Drei
- **UI Components:** Shadcn/UI, Lucide Icons

## ✨ Features

- **Immersive 3D Backgrounds:** Custom particle fields and interactive backgrounds using Three.js.
- **Premium Aesthetics:** Dark futuristic theme with Aurora gradients, soft shadows, and magnetic buttons.
- **Performance Optimized:** Fully optimized for speed and SEO.
- **Dynamic Content:** Showcasing GitHub activity, competitive programming focus, and elite projects.

## 💻 Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ronak-kumar06/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser:**
   Navigate to [http://localhost:3000](http://localhost:3000) to see the portfolio locally.
